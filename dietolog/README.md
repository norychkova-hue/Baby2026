# Бережный диетолог — бот (этап 1)

Telegram-бот: рассказываешь голосом или текстом, что ела и как себя чувствуешь,
бот записывает и мягко отвечает. Калории не считает. Вечером напоминает о себе,
по воскресеньям подводит итог недели и предлагает одну привычку.

Архитектура и принципы — в [`../docs/dietolog-architecture.md`](../docs/dietolog-architecture.md).

## Что понадобится

1. **Python 3.11+** на компьютере (python.org → Downloads).
2. **Бот в Telegram:** напиши [@BotFather](https://t.me/BotFather) → `/newbot` → получишь токен.
3. **Ключ Claude:** console.anthropic.com → API Keys.
4. **Ключ OpenAI** (для Whisper): platform.openai.com → API Keys.

> Anthropic и OpenAI не работают с российских IP и российскими картами. Если ты в России,
> на компьютере с ботом нужен VPN, а для оплаты — зарубежная карта.

## Запуск

```bash
cd dietolog
python -m venv .venv
# Windows:  .venv\Scripts\activate
# macOS:    source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env          # Windows: copy .env.example .env
```

Заполни `.env`: `TELEGRAM_TOKEN`, `ANTHROPIC_API_KEY`, `OPENAI_API_KEY`. Потом:

```bash
python main.py
```

Напиши своему боту `/start`: он пришлёт твой Telegram ID. Впиши его в `.env`
как `ALLOWED_USER_ID` и перезапусти. Больше никто пользоваться ботом не сможет.

## Как это работает на домашнем компьютере

- Бот сам забирает сообщения из Telegram (long polling), поэтому ему не нужны ни белый IP, ни HTTPS.
- Если компьютер выключен, сообщения ждут в Telegram до суток и обработаются при запуске.
- Вечернее напоминание приходит, пока бот запущен. Если в `REMIND_TIME` компьютер был
  выключен, напоминание придёт при запуске (до 23:00).
- Все записи лежат в одном файле `dietolog.sqlite3` рядом с кодом. Для резервной копии
  достаточно его скопировать.

## Команды

| Команда            | Что делает                                           |
|--------------------|------------------------------------------------------|
| голосовое / текст  | отчёт о еде, движении, сне, самочувствии или вопрос  |
| `/weight 68.5`     | вес (лучше раз в неделю, утром). Можно голосом: «взвесилась, 68 и 5» |
| `/waist 78`        | талия, см (раз в месяц), тоже можно голосом          |
| `/week`            | итог недели и фокус на следующую                     |
| `/focus`           | кодекс и фокус недели; `/focus 3` — выбрать пункт самой |
| `/challenge`       | челленджи недели: до трёх целей, выбираешь сама. `/challenge 1` — взять идею, `/challenge не есть стоя` — своя цель, `/challenge убрать 1`. Голосом тоже: «беру челлендж не перекусывать» |
| `/undo`            | удалить последний отчёт вместе с замерами (например, если голос распознался криво) |
| `/birth 2026-11-20`| дата родов                                           |
| `/settings`        | кормление грудью, скрывать цифры веса |

## Файлы

- `main.py` — бот: команды, голос, напоминания
- `coach.py` — запросы к Claude: разбор отчёта и итог недели
- `codex.py` — твой кодекс: 7 принципов из твоих заметок, из них выбирается фокус недели; там же идеи челленджей
- `challenges.py` — челленджи недели
- `prompts.py` — рамки и тон бота, юмор
- `stt.py` — голос → текст через Whisper
- `db.py` — SQLite

Бот не заменяет врача. При тревожных симптомах он сам посоветует обратиться к врачу.
