# Сон и кормления малыша — архитектура

Telegram-бот с Mini App: записываю сон, кормления, прогулки и вес, а приложение мягко подсказывает,
когда будить, когда укладывать и во сколько отбой — чтобы выйти на стабильный ночной сон без ночных
«гуляний». Пользователь один (мама, один телефон). Готовим до рождения, чтобы писать с первых дней.

Методическая база — гайды консультанта по сну Кати Мирошниковой «Сон 0–4 мес» и «Сон 5–9 мес»
(нормы Национального фонда сна), плюс рекомендации по весу/кормлениям оттуда же. Всё, что выдаёт
приложение, — **мягкие подсказки**, не медицина. Главный ориентир — состояние ребёнка, цифры вторичны.

## 0. Главный принцип — помощник для очень уставшей мамы

Основной результат: **не пропустить кормление, вовремя уложить/разбудить, выйти на стабильную ночь.**
Всё, что на это не влияет, — необязательно и по умолчанию скрыто или выключено.

- **Одно нажатие на событие.** Обязательных полей нет: время ставится само, тип сна (день/ночь)
  определяется сам. Всё остальное (сторона груди, место сна, как засыпал) — по желанию.
- **Один экран:** что сейчас + что дальше + одна большая кнопка. Цифры, графики, справка — за «Подробнее».
- **Мало сообщений.** По умолчанию бот пишет только: «пора кормить/будить», «скоро укладывать»
  и одну короткую утреннюю сводку. Остальные напоминания включаются в настройках.
- **Один совет в день, не список.** Если движок видит проблему — в утренней сводке один маленький шаг
  («сегодня второе бодрствование на 10 мин длиннее»), без оценок «плохо/хорошо».
- **Ошибки прощаются.** Забыла нажать — «указать время» или `−5/−10/−15 мин`; нажала лишнее — «отменить».
- **Спокойный тон.** Никаких красных тревог и «вы не уложились в норму»; предупреждения только там,
  где стоит позвонить педиатру (вес).

| Обязательно (влияет на результат) | Необязательно (скрыто / выключено по умолчанию) |
|---|---|
| Уснул / Проснулся | место сна, как засыпал / как проснулся |
| Кормление (одно нажатие = время начала) | сторона груди, длительность, что в прикорме |
| Вес (раз в неделю, в первые 2 недели — чаще) | графики, календарь скачков, справка |
| Прогулка (старт/стоп) — нужна, чтобы сон в коляске учёлся | время на улице, «свет до полудня» |

## 1. Общая схема

```
┌────────────── Telegram ──────────────┐
│  Mini App (основной интерфейс)       │   статус, большие кнопки, лента дня,
│  Чат бота (напоминания + быстрые      │   план, графики, правка записей
│  кнопки, когда Mini App не открыт)    │
└───────────────┬──────────────────────┘
                │ HTTPS (initData Telegram → проверка подписи, доступ только моему user id)
┌───────────────▼──────────────────────┐
│  Сервер (Node.js)                     │
│   api/        REST для Mini App       │
│   bot/        grammY: кнопки, команды │
│   scheduler/  напоминания по плану    │
│   core/       движок (чистые функции) │
│   db/         SQLite                  │
└──────────────────────────────────────┘
```

- **Mini App** — основной интерфейс: одна страница, открывается кнопкой в боте.
- **Бот** — напоминания (приходят даже при заблокированном телефоне) и дублирующие быстрые кнопки.
- **core/** не знает ни про Telegram, ни про БД: вход — профиль + записи + «сейчас», выход — статистика,
  план и подсказки с объяснением причины. Покрыт unit-тестами (`node --test`).
- Сервер работает на **домашнем компьютере** (см. §10) — код от хостинга не зависит.

## 2. Данные

`[опц.]` — необязательное поле, в интерфейсе скрыто за «ещё».

```
profile   birth_at            дата и время рождения
          due_date            ПДР — скорректированный возраст (если родится раньше срока)
          birth_weight_g
          timezone            берётся из Telegram автоматически
          settings            [опц.] свои окна бодрствования / интервал от педиатра / какие напоминания

sleep     start, end
          kind                day | night — определяется сам
          place               [опц.] кроватка | на руках | коляска | слинг (во время прогулки = коляска сам)
          fell_asleep         [опц.] легко | долго | со слезами
          woke_up             [опц.] довольный | с плачем

feeding   start
          type                breast | solids (кнопка «Прикорм» появляется с 6 мес)
          end, side           [опц.]
          product, amount     [опц.] для прикорма

walk      start, end

weight    date, grams
```

Правила записи, взятые из гайдов (всё считается само, маме ничего не нужно размечать):
- Бодрствование (ВБ) — от открытия глаз до засыпания; укладывание входит в ВБ.
- «Уснул» в течение 20 мин после «Проснулся» — это продлённый сон, записи склеиваются в **один** сон.
- Ночное кормление с закрытыми глазами — просто нажать «Кормление», сон не прерывается.
- Ночное «гуляние» — это «Проснулся» ночью и «Уснул» через ≥ 30 мин. Отдельной сущности нет.
- Сутки считаются от утреннего подъёма до следующего утреннего подъёма.

- До 4 мес суточный сон 14–17 ч, но 11–19 ч — тоже вариант нормы.
- Цикл сна: до 3 мес 30–50 мин (сны по 15–30 мин до 3 мес — физиологическая норма),

- Ночные кормления на ГВ (справочно): 5–6 мес ≈ 3–4, 6–10 мес ≈ 2–4.

## 4. Движок (`core/`)

Все функции чистые, каждая подсказка несёт `reason` — человеческое объяснение «почему».

| Модуль | Что делает |
|---|---|
| `age.js` | Возраст фактический и скорректированный (от ПДР), неделя жизни от ПДР |
| `norms.js` | Нормы для возраста (таблица выше + пользовательские правки) |
| `stats.js` | Итоги суток: сон день/ночь, число снов, отрезки ВБ, гуляния, время на улице, кормления |
| `individual.js` | **Индивидуальные нормы** по дневнику за последние 5 дней (метод из гайда): средний дневной, ночной, суточный сон → суточное ВБ = 24 ч − сон → средний отрезок ВБ = суточное ВБ / (снов + 1). Гуляния вычитаются из ночи и прибавляются к ВБ |
| `feeding.js` | Режим «будить на кормление» (§5) и время следующего кормления |
| `weight.js` | Динамика веса: потеря от рождения в %, восстановление, прибавка г/нед и г/мес |
| `planner.js` | План на остаток суток (§6) |
| `diagnose.js` | Разбор повторяющихся проблем за 3–5 дней (§7) |
| `leaps.js` | Календарь скачков развития от ПДР |

### Какой норматив использовать
1. Первые дни (< 5 дней записей) — табличная норма по возрасту.
2. Когда есть 5 дней — индивидуальные нормы, если они в пределах возрастного коридора; если вышли
   за коридор — используем их, но показываем предупреждение («ВБ 3,5 ч в 5 мес — это заметно выше
   нормы, проверьте признаки перегула»).
3. Пользовательские правки в настройках имеют приоритет.
4. Признаки усталости важнее таймера: в подсказке всегда «укладывать ≈ 14:10 или раньше, если
   появились признаки усталости».

## 5. Кормление (грудное до года, прикорм с 6 мес)

**Будить на кормление** (гайд 0–4, стр. 50) — если:
- вес ещё не вернулся к весу при рождении, **или**
- прибавка ниже 150–200 г/нед, **или**
- в этих условиях ребёнок спит ночью без кормления больше 4 ч.

**Перестаём будить**, когда вес при рождении восстановлен и прибавка ≥ 150–200 г/нед.

Режимы в `feeding.js`:

| Режим | Условие | Днём | Ночью |
|---|---|---|---|
| Контроль набора | вес не восстановлен или прибавка < 150 г/нед | напомнить через 3 ч от начала прошлого кормления | будить, если > 4 ч |
| Хороший набор | вес восстановлен, прибавка ≥ 150 г/нед | по требованию, мягкое напоминание, если > 3 ч | не будить |
| От педиатра | ручная настройка | свой интервал | свой интервал |

Ориентиры по прибавке для 5–9 мес на ГВ — 200–400 г/мес. Если прибавка ниже ориентира или потеря
веса после рождения > 10%, бот предлагает обсудить это с педиатром.

**Кормление и сон** (гайд 0–4, стр. 49):
- засыпает на груди → ритм «сон — бодрствование — кормление — сон»;
- не засыпает на груди → «сон — кормление — бодрствование — сон».

**Прикорм с 6 мес** (гайд 5–9, стр. 63–69):
- в записи кормления появляется тип «прикорм»;
- ориентир: 6–8 мес — 2–3 приёма + 1–2 перекуса, ≈200 ккал к грудному молоку;
  9–10 мес — 3–4 приёма, ≈300 ккал;
- `diagnose` ищет **перевёрнутый график кормлений**: днём 3–4 прикладывания, ночью 6–10. Это частая
  причина ночных пробуждений после 6 мес. Подсказка: больше груди днём (в тихой комнате, вокруг
  снов), не заменять грудь низкокалорийным прикормом.

## 6. Планировщик (`planner.js`)

Возвращает: когда укладывать, когда (мягко) будить, ориентир отбоя, подсказки по ходу дня.

**Когда укладывать** = пробуждение + отрезок ВБ, с поправками:
- после короткого сна ВБ чуть короче среднего, после длинного — чуть длиннее (гайд 0–4, стр. 45);
- с 5 мес ВБ нарастает к вечеру: последнее ВБ перед ночью самое длинное (гайд 5–9, стр. 30);
- одно напоминание за 20 мин: «скоро укладывать — можно замедляться, смотрим на признаки усталости».

**Когда будить** — раньше всего из:
- время кормления (§5);
- максимум одного дневного сна (2,5–3 ч до 4 мес, 2–2,5 ч с 5 мес);
- исчерпан дневной сон по норме;
- после пробуждения уже не успеть набрать нужное ВБ перед ночным отбоем (поздний последний сон).

Будим мягко: «пора создавать условия для пробуждения» (свет, бытовой шум), а не жёстко.

**Отбой** — конец последнего сна + последнее ВБ; ночь рассчитываем так, чтобы до утреннего подъёма
было 10–11 ч (при исправлении путаницы день/ночь — 9–10 ч до подъёма в 8–9 утра).

**По возрасту:**
- **0 – ~2,5 мес.** Режима нет, ребёнок «донашивается». Главное — кормления, признаки усталости,
  разница день/ночь. Сны по 15–30 мин — норма. Будим только на кормление и если дневной сон > 2,5–3 ч.
- **~2,5–4 мес.** Ритм дня от суточной нормы: сны не привязаны к часам, а следуют за ВБ; 2–3
  «управляемых» сна продлеваем, остальные — нет (пример ритма в гайде 0–4, стр. 45–46).
- **5–9 мес.** Фиксация утреннего подъёма (±15 мин, 1–2 недели), распределение сна по суткам,
  ВБ с нарастанием к вечеру, 5 дней на проверку нового ритма.
- **С 10 мес.** Возможен режим по часам.

**Переход на меньшее число снов** (4→3 в 4,5–6 мес, 3→2 в 7–9 мес). Признаки: ВБ выросло, протест
на последний сон, ночные гуляния, ранние подъёмы. Режим — **плавающий**: дни с бо́льшим и меньшим
числом снов чередуются (например, 4/4/3/4/4/3 → 3/4/3/4 → 3/3/4/3), а среднее суточное ВБ за
несколько дней держится на норме ребёнка. Планировщик на каждый день предлагает оба варианта
(«сегодня 3 сна, отбой ≈ 20:20» / «сегодня 4 сна, отбой ≈ 21:20») и показывает баланс ВБ за неделю.

## 7. Диагностика (`diagnose.js`) — главное для стабильной ночи

Смотрит 3–5 последних суток и называет вероятную причину и один маленький шаг.

**Недогул** (мало ВБ, гайд 5–9, стр. 45–47): долго засыпает без слёз; трудно переложить; днём
30–40 мин и просыпается довольным; ночью гуляет ≥ 30 мин с открытыми глазами; подъём до 6:00 при
отбое не раньше 20:00.
→ удлинить самый короткий отрезок ВБ на 5–15 мин, дать 1–2 дня на адаптацию, потом следующий.
Если одно ВБ короткое, а другое длинное — короткое удлинить, длинное укоротить.

**Перегул** (гайд 5–9, стр. 48): засыпает со слезами; частые ночные пробуждения с плачем; короткие
сны с плачем; днём капризный или вялый.
→ сократить ВБ, раньше замедляться, искать «окно в сон».

**Пересып днём:** дневной сон выше нормы при короткой ночи, ночные гуляния.
→ урезать суммарный дневной сон (пример: ночь 10 ч + день 3,5 ч в 7 мес → урезать день;
ночь 11,5 ч + день 2 ч → урезать ночь).

**Путаница день/ночь** (0–4 мес): длинный дневной сон 4+ ч, ночью гуляния.
→ будить в 8–9 утра, не давать днём спать дольше нормы, свет и прогулка до полудня, темнота ночью.

**Накопленный недосып** (0–4 мес): регулярно бодрствует по несколько часов подряд.
→ сократить ВБ, продлевать все сны до 3 дней подряд, не будить.

**Перевёрнутый график кормлений** (6+ мес) — см. §5.

Диагностика работает и без отметок «как засыпал / как проснулся» — по времени сна, длине ВБ, ночным
гуляниям и ранним подъёмам. Если отметки есть, совет точнее (легче отличить недогул от перегула).
Наружу выходит **не больше одного совета в день** — самый важный, в утренней сводке.

## 8. Интерфейс

### Mini App — один главный экран
```
┌─────────────────────────────────┐
│  Спит 1 ч 10 мин                │  ← что сейчас
│  Будить ≈ 13:40 — кормление     │  ← что дальше и почему (одна строка)
│                                 │
│      [  ☀️  Проснулся  ]        │  ← одна большая кнопка, меняется по состоянию
│                                 │
│   🤱 Кормление     🚶 Прогулка   │  ← вторичные кнопки
│                                 │
│   Сегодня: сон 9 ч 40 · 6 корм. │  ← одна строка итогов
│   Подробнее ›                   │
└─────────────────────────────────┘
```
- После нажатия — тихая плашка «Записано 13:05 · `−5` `−10` `−15` · изменить · отменить».
- **«Подробнее»** (открывается, только если захочется): лента суток и план, сводка против нормы,
  вес и график, календарь скачков, справка (чек-лист безопасного сна, ритуалы, мостик ко сну),
  необязательные поля, настройки напоминаний.
- **Вес** — бот сам раз в неделю спрашивает «Есть свежий вес?» (в первые 2 недели — чаще), не надо помнить.
- Крупный шрифт, тёмная тема ночью (следует теме Telegram), нажимается одной рукой.

### Бот (чат)
- Те же кнопки в клавиатуре чата — если Mini App открывать неудобно.
- **Напоминания по умолчанию — только три:**
  1. «Через 15 мин пора кормить» / «Пора будить на кормление» (ночью со звуком — только в режиме
     «контроль набора», иначе ночью тишина);
  2. «Через 20 мин укладывать — можно начинать замедляться»;
  3. утренняя сводка: 2–3 строки итогов + один совет (если есть) + скачок (если идёт).
- **Выключены по умолчанию** (включаются в настройках): «сон идёт 2,5 ч — можно будить»,
  «приглушить свет перед ночью», «прогулка до полудня», «на прогулке — пора домой», «покормить перед выходом».
- Бот не пишет повторно одно и то же: напоминание обновляется в том же сообщении.

### Прогулки
- «Прогулка» — старт/стоп. Сон во время прогулки сам получает место «коляска» и считается обычным
  дневным сном.
- Продление сна в коляске — до 15–20 мин укачивания, потом начинается ВБ (правило «20 минут» из §2).

### Календарь скачков (`leaps.js`, недели от ПДР)
5; 8–9; 11–12; 15–19 (пик 17 — регресс 4 мес); 23–26; 29–30 (пик сепарационной тревоги); 34–37.
Пик физиологического плача — 6–8 недель от рождения. Показывается одной строкой в утренней сводке:
«Идёт скачок — сон может временно ухудшиться, это нормально».

## 9. Этапы

1. **До родов (MVP).** Профиль (дата рождения, ПДР, вес при рождении); кнопки сон / кормление /
   прогулка / вес; правка и отмена; режим «будить на кормление» по весу; напоминание о кормлении;
   утренняя сводка; ежедневная резервная копия. Движок + тесты.
2. **~2–6 недель.** Подсказка «когда укладывать» по окнам ВБ, путаница день/ночь, скачки.
3. **~2,5–4 мес.** Индивидуальные нормы по 5 дням, ритм с «управляемыми» снами, один совет в день
   (недогул / перегул / пересып).
4. **5+ мес.** Фиксация подъёма, плавающий режим при переходе 4→3→2 сна, прикорм и перевёрнутый
   график кормлений.

## 10. Домашний сервер и сохранность данных

**Что это значит:** бот и Mini App работают, только пока компьютер включён и подключён к интернету.

| Если компьютер… | Что будет |
|---|---|
| выключен / уснул / нет интернета | кнопки не отвечают, **напоминания не приходят** |
| снова включился | бот поднимается сам (автозапуск); нажатия в чате за время простоя Telegram хранит до 24 ч — бот их подхватит |

- Отключаем «спящий режим» и ставим автозапуск бота при включении компьютера.
- **Бот через long polling** — не нужен белый IP и открытые порты.
- **Mini App** должен открываться по HTTPS-адресу → бесплатный Cloudflare Tunnel с компьютера.
  Домен покупать не нужно: если адрес туннеля сменится, бот при старте сам обновит кнопку Mini App.
- ⚠️ Самое важное напоминание — «разбудить на кормление ночью» в первые недели. Если компьютер
  выключится ночью, его не будет. Поэтому в режиме «контроль набора» бот советует **продублировать
  будильником на телефоне** — пока вес не восстановится.

**Данные не потеряются:**
- Все записи — в одном файле SQLite на компьютере.
- **Каждую ночь бот присылает резервную копию прямо в чат** (файл). Она лежит в облаке Telegram:
  даже если компьютер сломается, данные на месте. Восстановление — переслать файл боту.
- В любой момент: кнопка «Выгрузить всё» (файл CSV — открывается в Excel / Google Таблицах).
- **Переезд** на VPS позже — скопировать один файл и перезапустить. Код от хостинга не зависит:
  один процесс Node + файл SQLite + переменные окружения `BOT_TOKEN`, `OWNER_TELEGRAM_ID`, `PUBLIC_URL`.
