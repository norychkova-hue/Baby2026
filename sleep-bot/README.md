# Сонный помощник — Telegram-бот

Бот для записи сна малыша.

- **Что он делает:** считает количество и длительность снов, подсказывает, когда укладывать и когда будить, и раз в неделю присылает отчёт со сравнением с нормами из гайда.
- **Как им пользоваться:** в чате с ботом есть кнопки «😴 Уснул / ☀️ Проснулся». Всё остальное — в приложении (Mini App), которое открывается прямо в Telegram.
- **Где работает:** на домашнем компьютере. Пока компьютер включён, бот работает, а данные хранятся в одном файле. Каждую ночь бот присылает резервную копию в чат.

Как всё устроено и почему именно так, описано в [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

## Запуск — один раз, примерно 15 минут

### 1. Создать бота в Telegram
1. Откройте в Telegram **@BotFather** и отправьте `/newbot`.
2. Придумайте боту имя и адрес, например `misha_sleep_bot`.
3. BotFather пришлёт **токен** — строку вида `123456789:AA…`. Сохраните его.

### 2. Установить Node.js
Нужен **Node.js 22.13 или новее**: https://nodejs.org → кнопка «LTS». Установите, как обычную программу.

### 3. Установить cloudflared — чтобы приложение открывалось в Telegram
Telegram открывает приложение только по защищённому адресу (https). Программа `cloudflared` бесплатно даёт такой адрес для домашнего компьютера. Не нужны ни роутер, ни белый IP, ни домен.
- **Windows:** скачайте `cloudflared-windows-amd64.msi` на странице https://github.com/cloudflare/cloudflared/releases/latest и установите.
- **macOS:** `brew install cloudflared`
- **Linux:** https://pkg.cloudflare.com/ или пакет из той же страницы releases.

Без cloudflared кнопки «Уснул / Проснулся» в чате тоже работают, но приложение не откроется.

### 4. Настроить
1. Скопируйте файл `.env.example` в `.env`, в той же папке `sleep-bot`.
2. Впишите в `.env` токен: `BOT_TOKEN=123456789:AA…`.
3. Если вы живёте не по московскому времени, поменяйте `TZ`, например `TZ=Asia/Yekaterinburg`.

### 5. Запустить
В папке `sleep-bot` выполните:
```
npm start
```
В окне появится строка «Бот запущен». Откройте своего бота в Telegram и отправьте `/start`. Тот, кто первым напишет `/start`, становится владелицей: бот личный, другим людям он отвечать не будет.

Затем нажмите «📱 Открыть приложение» и укажите дату рождения малыша, ПДР и вес при рождении. Можно сделать это заранее, до родов: указать примерную дату, а потом поправить.

### 6. Чтобы бот работал всегда
- **Отключите спящий режим компьютера** — когда компьютер спит, напоминания не приходят.
- **Включите автозапуск:**
  - **Windows:** нажмите Win+R, введите `shell:startup` и положите в открывшуюся папку ярлык на `scripts\start-windows.bat`.
  - **macOS:** инструкция внутри файла `scripts/com.sleepbot.plist`.
  - **Linux:** добавьте `scripts/start-mac-linux.sh` в автозапуск или создайте systemd-сервис.

Скрипты сами перезапускают бота, если он упадёт.

## Что важно знать

- **Компьютер выключен — напоминаний нет.** Нажатия в чате за это время Telegram хранит до суток, и бот их подхватит после включения. Пока вес малыша не вернулся к весу при рождении, продублируйте ночные кормления будильником на телефоне.
- **Данные не потеряются.** Каждую ночь в 3:30 бот присылает в чат файл `sleep-backup-….db`. Чтобы восстановить данные, перешлите этот файл боту.
- **Выгрузка:** `/export` — все записи в таблицу (Excel или Google Таблицы). Удобно показать консультанту.
- **Отчёт:** приходит сам каждый понедельник в 9:00 за прошедшую неделю. В любой момент можно запросить его командой `/report`. День и время меняются в `.env`, параметр `WEEKLY_REPORT`.
- **Адрес приложения при каждом запуске новый.** Это особенность бесплатного туннеля; бот сам обновляет кнопки. Если нужен постоянный адрес, впишите свой https-адрес в `PUBLIC_URL`.
- **Кормления выключены.** Включаются в приложении: Настройки → «Записывать кормления».

## Команды бота
| | |
|---|---|
| `😴 Уснул` / `☀️ Проснулся` | отметить сон; под ответом есть «−10 / −20 / −30 мин» и «Отменить» |
| число, например `5230` | записать вес в граммах |
| `/report` | отчёт за неделю |
| `/export` | все записи таблицей |
| `/backup` | резервная копия сейчас |

## Для разработки
```
npm test        # тесты движка, бота и API (без настоящего Telegram)
npm run dev     # приложение на http://127.0.0.1:8080 без проверки Telegram
```
Код:
- `src/core/` — расчёты (нормы, сны, план, напоминания, отчёт), без зависимостей;
- `src/bot/` — Telegram;
- `src/server.js` — API для Mini App;
- `webapp/` — само приложение.

Сторонних библиотек нет: используется встроенный в Node модуль SQLite.
