# Считалка схваток

Простая страница для подсчёта схваток: одна большая кнопка «Началась / Закончилась схватка»,
журнал с длительностью и интервалами, статистика за последний час и подсказка — какой сейчас
период родов и пора ли ехать в роддом (правило 5-1-1 для первых родов, раньше — для повторных).

Открыть: `index.html` в любом браузере на телефоне. Данные хранятся только в этом браузере.

`src/timer.html` — та же страница без обёртки `<html>/<head>` (для публикации как Artifact).

Это помощник, а не медицинский диагноз: при тревожных признаках звоните 103 / 112.
