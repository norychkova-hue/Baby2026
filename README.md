# Роды 2026: помощник в Telegram

Два экрана, между ними переход ссылкой в шапке:

- **`breathing.html` — Дыхание в родах.** Выберите период родов (латентная, активная, переходный,
  потуги, рождение головки) и дышите за кругом: растёт — вдох, сжимается — выдох. Под кругом подсказки
  «Малышу сейчас»: что происходит с ребёнком и почему важно не задерживать дыхание. Когда
  нажимаете «Схватка прошла», сразу включается отдых — два глубоких вдоха «для малыша».
  Есть вибрация на каждый вдох и выдох (в Telegram — встроенная) и подсказки голосом.
- **`index.html` — Считалка схваток.** Журнал, интервалы и подсказка, когда ехать в роддом.

`tg.js` подключает страницы к Telegram: тема как в Telegram, приложение на весь экран, вибрация,
вопрос «закрыть?», если случайно смахнуть окно посреди схватки. В обычном браузере он ничего не делает.

`src/*.html` — те же страницы без обёртки `<html>/<head>` (для публикации как Artifact).

## Как сделать приложение в Telegram (один раз, ~5 минут)

1. **Включить сайт.** GitHub → репозиторий → *Settings* → *Pages* → *Build and deployment*:
   *Source* = **Deploy from a branch**, *Branch* = `claude/labor-breathing-app-wb1x4k`, папка `/ (root)` → *Save*.
   Через 1–2 минуты страница будет по адресу
   `https://norychkova-hue.github.io/Baby2026/breathing.html` — откройте её в браузере, чтобы проверить.
2. **Создать бота.** В Telegram откройте **@BotFather** → `/newbot` → придумайте имя
   (например «Дыхание в родах») и адрес бота, который кончается на `bot`.
3. **Кнопка приложения.** В @BotFather: `/mybots` → ваш бот → *Bot Settings* → *Menu Button* →
   отправьте адрес `https://norychkova-hue.github.io/Baby2026/breathing.html` и название кнопки, например «Дышать».
4. **(Необязательно) Главное приложение.** `/mybots` → бот → *Bot Settings* → *Configure Mini App* →
   *Enable Mini App* → тот же адрес. Тогда бот откроется в приложение прямо из поиска и из профиля.
5. Откройте своего бота, нажмите кнопку «Дышать» и закрепите чат сверху — теперь приложение в одно касание.

Это помощник, а не замена врачу и акушерке. При тревожных признаках звоните 103 / 112.
