# Бережный диетолог — архитектура (черновик)

Telegram-бот + мини-приложение. Помогает после родов мягко прийти к своему весу
и сохранить мышцы. Главное — здоровье ЖКТ и отношения с едой, а не скорость.

## Принципы продукта

- **Никаких калорий, граммов и шагов.** Отмечаем только факт («поела», «гуляла»,
  «была силовая») и ощущения.
- **Учимся слушать тело.** Голод до еды, сытость после, комфорт живота, энергия, сон.
- **Вес — не каждый день.** Раз в неделю, по желанию, показываем только тренд.
  Можно вообще скрыть цифру. Плюс раз в месяц — обхват талии.
- **Одна маленькая привычка на неделю** («фокус недели»), а не десять правил сразу.
- **Бережный темп:** не больше ~0,5 кг в неделю, при грудном вскармливании медленнее.
  Никаких голоданий, детоксов и жёстких запретов.
- **Мышцы:** белок отмечаем «был / не было в тарелке», силовые — фактом.
  Тренировки только после разрешения врача (диастаз, тазовое дно).
- **Не врач.** При тревожных симптомах (кровь в стуле, сильная боль, резкая потеря веса,
  признаки послеродовой депрессии) бот советует обратиться к врачу.

## Схема

```
   Голосовое / текст в чат ──┐
                             ▼
┌──────────────┐     ┌───────────────────┐     ┌──────────────────┐
│ Telegram-бот │────▶│ Бэкенд (1 сервис) │────▶│ SQLite (1 файл)  │
└──────────────┘     │  - вебхук бота    │     └──────────────────┘
┌──────────────┐     │  - API мини-аппа  │
│ Мини-апп     │────▶│  - расписание     │──▶ Распознавание речи (голос → текст)
│ (1 HTML)     │     └───────────────────┘──▶ Claude (текст → отметки, ответы)
└──────────────┘
```

### 1. Бот — основной вход

- Голосовые сообщения Telegram записывает сам, это надёжнее, чем микрофон внутри
  мини-аппа (на iPhone в Telegram он часто не работает).
- Бэкенд скачивает голосовое → распознаёт речь → Claude разбирает текст на отметки
  → бот коротко отвечает: «Записала: обед, сытость 7/10, лёгкое вздутие. Спасибо, что заметила».
- Бот сам пишет 1–2 раза в день (время настраивается), по воскресеньям — мягкий итог недели.

### 2. Мини-апп — быстрые отметки и обзор

- Кнопки-факты: 🍽 поела · 🥩 был белок · 🥦 овощи · 💧 вода · 🚶 прогулка · 🏋️ силовая · 😴 сон.
- Шкалы ощущений в один тап: голод до еды, сытость после, живот, энергия, настроение.
- Неделя в виде «погодной карты» ощущений, а не таблицы с цифрами.
- Фокус недели и тренд веса (по желанию).
- Одна статичная HTML-страница (как считалка схваток), хостинг — GitHub Pages.

### 3. Бэкенд

- Python: aiogram (бот) + FastAPI (API) + APScheduler (напоминания) — один процесс.
- Вход в мини-апп — проверка подписи Telegram `initData`, доступ только с одного Telegram ID.
- Хостинг: маленький VPS или Fly.io/Render (нужен HTTPS для вебхука).

### 4. ИИ

- **Распознавание речи:** Whisper API или Yandex SpeechKit (хорошо понимает русский).
  Claude сам аудио не принимает, поэтому этот шаг отдельный.
- **Разбор отчёта:** Claude Haiku 4.5 превращает текст в JSON-отметки (дёшево и быстро).
- **Коучинг:** Claude Sonnet 5 — ответы, недельный итог, выбор фокуса недели.
  В системном промпте: принципы выше + контекст (ГВ или нет, срок после родов,
  разрешение врача на нагрузки).

## Данные

| Таблица    | Что хранит                                                                    |
|------------|-------------------------------------------------------------------------------|
| `profile`  | дата родов, ГВ да/нет, цель (диапазон веса), разрешение на нагрузки, время напоминаний |
| `entries`  | время, тип (еда / движение / сон / вода / самочувствие), теги, исходный текст голосового |
| `feelings` | привязка к записи: голод 0–10, сытость 0–10, живот (комфорт / тяжесть / вздутие / изжога), энергия, настроение, стул (по желанию) |
| `measures` | вес и талия — редко, для тренда                                               |
| `focus`    | фокус недели, итоги недели                                                    |

## Этапы

1. **MVP — только бот.** Голос/текст → отметки → ответ. Вечернее напоминание.
2. **Мини-апп.** Быстрые отметки и обзор недели.
3. **Коучинг.** Недельный итог, фокус недели, замечание связей
   («вздутие чаще после поздних ужинов»).
