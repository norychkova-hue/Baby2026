# Бережный диетолог — архитектура (черновик)

Telegram-бот + мини-приложение. Помогает после родов мягко прийти к своему весу
и сохранить мышцы. Главное — здоровье ЖКТ и отношения с едой, а не скорость.

## Принципы продукта

- **Никаких калорий, граммов и шагов.** Отмечаем только факт («поела», «гуляла») и ощущения.
- **Учимся слушать тело.** Голод до еды, сытость после, комфорт живота.
- **Вес — не каждый день.** Раз в неделю, по желанию, показываем только тренд.
  Можно вообще скрыть цифру. Плюс раз в месяц — обхват талии.
- **Одна маленькая привычка на неделю** («фокус недели»), а не десять правил сразу.
- **Бережный темп:** она кормит грудью (план — год), поэтому медленно и без дефицитов.
  Никаких голоданий, детоксов и жёстких запретов.
- **Без спорта:** из движения — только прогулки. Мышцы бережём белком: «был / не было в тарелке».
- **Не врач.** При тревожных симптомах (кровь в стуле, сильная боль, резкая потеря веса,
  признаки послеродовой депрессии) бот советует обратиться к врачу.

## Схема

```
   Голосовое / текст в чат ──┐
                             ▼
┌──────────────┐     ┌───────────────────┐     ┌──────────────────┐
│ Telegram-бот │────▶│ Бэкенд (1 сервис) │────▶│ SQLite (1 файл)  │
└──────────────┘     │  - вебхук бота    │     └──────────────────┘
┌──────────────┐     │  - API мини-аппа  │
│ Мини-апп     │────▶│  - расписание     │──▶ Распознавание речи (голос → текст)
│ (1 HTML)     │     └───────────────────┘──▶ Claude (текст → отметки, ответы)
└──────────────┘
```

### 1. Бот — основной вход

- Голосовые сообщения Telegram записывает сам, это надёжнее, чем микрофон внутри
  мини-аппа (на iPhone в Telegram он часто не работает).
- Бэкенд скачивает голосовое → распознаёт речь → Claude разбирает текст на отметки
  → бот коротко отвечает: «Записала: обед, сытость 7/10, лёгкое вздутие. Спасибо, что заметила».
- Бот сам пишет 1–2 раза в день (время настраивается), по воскресеньям — мягкий итог недели.

### 2. Мини-апп — быстрые отметки и обзор

- Кнопки-факты: 🍽 поела · 🥩 был белок · 🥦 овощи · 💧 вода · 🚶 прогулка · 😴 сон · 🍼 кормление.
- Шкалы ощущений в один тап: голод до еды, сытость после, живот.
- Неделя в виде «погодной карты» ощущений, а не таблицы с цифрами.
- Фокус недели и тренд веса (по желанию).
- Одна статичная HTML-страница (как считалка схваток), хостинг — GitHub Pages.

### 3. Бэкенд

- Python + aiogram, один процесс, напоминания — простой цикл в том же процессе.
- Работает на домашнем компьютере: long polling, поэтому не нужны ни белый IP, ни HTTPS.
- Доступ только с одного Telegram ID (`ALLOWED_USER_ID`).
- Для мини-аппа (этап 2) понадобится HTTPS-адрес для API: Cloudflare Tunnel с того же компьютера
  или перенос на маленький сервер. Вход — проверка подписи Telegram `initData`.

### 4. ИИ

- **Распознавание речи:** Whisper (OpenAI). Claude сам аудио не принимает, поэтому этот шаг отдельный.
- **Claude, один запрос на отчёт:** разбирает текст на записи (структурированный JSON)
  и сразу пишет ответ. Раз в неделю — итог и фокус недели. Модель задаётся в `CLAUDE_MODEL`.
  В системном промпте — принципы выше, в запросе — контекст: кормление, срок после родов,
  фокус недели, записи за последние дни.

## Данные

| Таблица    | Что хранит                                                                    |
|------------|-------------------------------------------------------------------------------|
| `profile`  | дата родов, ГВ да/нет, скрывать ли вес, время напоминаний |
| `entries`  | время, тип (еда / движение / сон / вода / самочувствие / стул), теги, заметка, ощущения (голод 0–10, сытость 0–10, живот), исходный текст |
| `measures` | вес и талия — редко, для тренда                                               |
| `weeks`    | итоги недели и фокус недели                                                    |

## Этапы

1. **Бот** (готов, `dietolog/`). Голос/текст → записи → ответ. Вечернее напоминание,
   итог и фокус недели по воскресеньям, вес/талия, настройки.
2. **Мини-апп.** Быстрые отметки и обзор недели.
3. **Глубже коучинг.** Замечание связей за месяцы («вздутие чаще после поздних ужинов»).

## Решения

- Кормление грудью — год.
- Бэкенд — домашний компьютер.
- Распознавание речи — Whisper.
